# Salesbot as a claude.ai artifact

`salesbot.html` is a browser-only version of salesbot published as a claude.ai artifact:
https://claude.ai/artifact/6YkVnFET8ApmLsBJfur2pV

- The Manager, Recruiter, HR and every hired bot run on Claude through the artifact's `sample`
  capability, on the signed-in viewer's own Claude account. No server or API key needed.
- The team, leads, out-tray and chat are saved in the artifact's `db` (readable and writable by
  people the artifact is shared with at Contributor level or above).
- Bots cannot browse or send. Drafted emails and texts wait in the out-tray; approve, copy and
  send them yourself.

Publish changes from Claude Code with the Artifact tool, using the same file path.
